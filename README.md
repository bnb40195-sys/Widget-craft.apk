# WidgetCraft Pro 📱✨
> **صانع ومحرر الويدجات ولوحات المفاتيح والخلفيات بالذكاء الاصطناعي (أوفلاين 100% بدون إنترنت)**

[![Build & Release Android APK](https://github.com/OWNER/REPOSITORY/actions/workflows/build-apk.yml/badge.svg)](https://github.com/OWNER/REPOSITORY/actions/workflows/build-apk.yml)

تطبيق أندرويد متكامل ومبني بأحدث تقنيات **Kotlin & Jetpack Compose (Material Design 3)** لتخصيص الشاشة الرئيسية ولوحة المفاتيح ومركز الإشعارات أوفلاين بالكامل.

---

## 🌟 الميزات الرئيسية (Key Features)

1. **لوحة المفاتيح والتشغيل التفاعلي (Interactive AI Keyboard)**:
   - إضافة أي صورة من المعرض ليقوم الذكاء الاصطناعي بتحليل تناغم ألوانها وتوليد سمة لوحة مفاتيح متناسقة فوراً أوفلاين.
   - إمكانية تشغيل واستخدام الصورة كخلفية مباشرة للوحة المفاتيح مع تظليل ناعم للمفاتيح لضمان سهولة القراءة.
   - حقل تجربة حية للكتابة مع دعم التبديل بين اللغتين العربية والإنجليزية، صف الأرقام، الرموز، والاهتزاز اللمسي (Haptic Feedback).
   - زر نسخ النص ومسحه بنقرة واحدة، وحفظ السمة في مكتبة السمات.

2. **توليد الخلفيات بالذكاء الاصطناعي (AI Wallpaper Studio)**:
   - تحليل مستويات إضاءة الصور وحساب درجة التعتيم الذكية (Dim Level) لتبقى الويدجات والأيقونات واضحة ومريحة للعين.
   - تدرجات فنية مدمجة (نيون سايبر، سديم فضائي، شفق الغروب، زمرد إسلامي، أسود AMOLED نقي).

3. **إختصارات التطبيقات في مركز الإشعارات (Notification Center Shortcuts)**:
   - شريط وصول سريع دائم في مركز إشعارات أندرويد (Status Bar / Notifications) يتيح تشغيل التطبيقات المفضلة (الهاتف، الرسائل، الكاميرا، المتصفح، الملاحظات) بضغطة زر واحدة.
   - مفتاح تشغيل/إيقاف مباشر مع إمكانية تثبيت وإلغاء تثبيت أي تطبيق في شريط الإشعارات.

4. **إدارة وعرض جميع الويدجات (All Widgets Studio)**:
   - عرض وتعديل جميع الويدجات المحفوظة، البحث، التصفية حسب النوع، وتثبيتها على شاشة الهاتف الرئيسية مباشرة بدون ملفات.
   - دعم التثبيت المباشر بالضغط المطول على شاشة الهاتف واختيار WidgetCraft.

5. **مفلتر إسلامياً ونظيف 100% (Halal & Clean)**:
   - خالٍ تماماً من صور النساء أو الحيوانات أو ذوات الأرواح، مع التركيز على التصاميم الهندسية، النيون، والمينيمال.

6. **حذف المتجر الإلكتروني**:
   - تم استبدال المتجر الإلكتروني بالكامل بأدوات الذكاء الاصطناعي المحلية التي تعمل بدون نت.

## 🚀 كيفية بناء وتحميل ملف APK عبر GitHub Actions

تم تجهيز هذا المشروع بملف عمل آلي في مسار `.github/workflows/build-apk.yml` يقوم ببناء ملف `WidgetCraft-debug.apk` تلقائياً عند دفع الكود إلى GitHub ورفعه إلى **GitHub Releases** للتحميل المباشر.

### خطوات التفعيل والتحميل:

1. **رفع المشروع إلى GitHub**:
   - من قائمة الإعدادات في **Google AI Studio**، اختر **Push to GitHub** أو قم بتصدير المشروع كملف ZIP ورفعه إلى مستودع GitHub الخاص بك.

2. **البناء التلقائي**:
   - بمجرد رفع الكود إلى الفرع `main` أو `master` (أو عند إنشاء Tag جديد مثل `v1.0.0`)، سيبدأ سير عمل GitHub Actions تلقائياً.
   - يمكنك متابعة تقدم البناء بالانتقال إلى تبويب **Actions** في مستودع GitHub.

3. **تحميل ملف APK المباشر**:
   - **الخيار الأول (من صفحة Releases)**:
     - انتقل إلى صفحة **Releases** في مستودعك على GitHub.
     - ستجد أحدث إصدار مع رابط مباشر لتحميل `WidgetCraft-debug.apk`.
   - **الخيار الثاني (من تشغيل الـ Action)**:
     - ادخل إلى آخر تشغيل ناجح في تبويب **Actions**.
     - في أسفل الصفحة، اضغط على **WidgetCraft-Debug-APK** لتحميل الملف المضغوط الذي يحتوي على الـ APK.

4. **التشغيل اليدوي (Workflow Dispatch)**:
   - يمكنك في أي وقت الذهاب إلى تبويب **Actions** > اختيار **Build & Release Android APK** > الضغط على **Run workflow** لبناء وتوليد APK جديد فوراً.

## 📲 كيفية تثبيت التطبيق على هاتفك

1. بعد تحميل ملف `WidgetCraft-debug.apk` على هاتفك، افتح الملف.
2. إذا طلب النظام الإذن، قم بتفعيل خيار **"السماح بتثبيت التطبيقات من هذا المصدر" (Install unknown apps)** لمتصفحك أو مدير الملفات.
3. اضغط على **تثبيت (Install)** ثم **فتح (Open)**.
4. استمتع بتجربة لوحة المفاتيح والويدجات وإختصارات الإشعارات بدون إنترنت!
