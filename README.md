# تطبيق الثيمات (Themes Pro) 📱✨
> **صانع ومحرر الويدجات ولوحات المفاتيح والخلفيات بالذكاء الاصطناعي**

[![Build & Release Android APK](https://github.com/OWNER/REPOSITORY/actions/workflows/build-apk.yml/badge.svg)](https://github.com/OWNER/REPOSITORY/actions/workflows/build-apk.yml)

تطبيق أندرويد متكامل ومبني بأحدث تقنيات **Kotlin & Jetpack Compose (Material Design 3)** لتخصيص الشاشة الرئيسية ولوحة المفاتيح ومركز الإشعارات بالكامل، مع مشغل فيديو مدمج ومتصفح ويب وتنزيل وسائط وتنبيهات الأذان.

---

## 🌟 الميزات الرئيسية (Key Features)

1. **الواجهة الرئيسية الشاملة (Full Dashboard)**:
   - لوحة تحكم عادية ومتكاملة مع بطاقة معاينة حية للويدجت النشط في منتصف الشاشة.
   - قسم الإلهام اليومي: آية قرآنية كريمة يومياً مع تشغيل صوتي عالي الدقة، وحدث في مثل هذا اليوم بالتاريخ الهجري والميلادي.
   - زر تبديل الأرقام الفوري 1234 ⇄ ١٢٣٤ على مستوى التطبيق والويدجات.
   - زر التبديل بين نظام الوقت 12h و 24h.
   - شريط سفلي سريع للتنقل: الرئيسية | الثيمات | المتصفح | الفيديوهات | الإعدادات.

2. **لوحة المفاتيح والتشغيل التفاعلي (Interactive AI Keyboard)**:
   - إضافة أي صورة ليقوم الذكاء الاصطناعي بتحليل تناغم ألوانها وتوليد سمة لوحة مفاتيح متناسقة فوراً.
   - إمكانية تشغيل واستخدام الصورة كخلفية مباشرة للوحة المفاتيح مع تظليل ناعم للمفاتيح لضمان سهولة القراءة.
   - حقل تجربة حية للكتابة مع دعم التبديل بين اللغتين العربية والإنجليزية، صف الأرقام، الرموز، والاهتزاز اللمسي (Haptic Feedback).

3. **توليد الخلفيات بالذكاء الاصطناعي (AI Wallpaper Studio)**:
   - تحليل مستويات إضاءة الصور وحساب درجة التعتيم الذكية (Dim Level) لتبقى الويدجات والأيقونات واضحة ومريحة للعين.
   - تدرجات فنية مدمجة (نيون سايبر، سديم فضائي، شفق الغروب، زمرد إسلامي، أسود AMOLED نقي).

4. **إختصارات التطبيقات في مركز الإشعارات (Notification Center Shortcuts)**:
   - شريط وصول سريع دائم في مركز إشعارات أندرويد (Status Bar / Notifications) يتيح تشغيل التطبيقات المفضلة (الهاتف، الرسائل، الكاميرا، المتصفح، الملاحظات) بضغطة زر واحدة.
   - مفتاح تشغيل/إيقاف مباشر مع إمكانية تخصيص الأيقونات.

5. **المتصفح المدمج ومشغل الفيديوهات ومركز التنزيل**:
   - متصفح ويب سريع وآمن لتشغيل أي موقع والبحث المباشر.
   - مشغل فيديو متطور يدعم دقة 1080p وكافة الصيغ (MP4, MKV, WebM, HLS).
   - أداة تنزيل الوسائط والملفات من الروابط المباشرة.

6. **مفلتر إسلامياً ونظيف 100% (Halal & Clean)**:
   - خالٍ تماماً من صور النساء أو الحيوانات أو ذوات الأرواح، مع التركيز على التصاميم الهندسية، النيون، والمينيمال.

## 🚀 كيفية بناء وتحميل ملف APK عبر GitHub Actions

تم تجهيز هذا المشروع بملف سير عمل آلي في مسار `.github/workflows/build-apk.yml` يقوم ببناء ملف `AlThemat-debug.apk` تلقائياً عند دفع الكود إلى GitHub ورفعه إلى **GitHub Releases** للتحميل المباشر بنقرة واحدة.

### خطوات التفعيل والتحميل:

1. **رفع المشروع إلى GitHub**:
   - من قائمة الإعدادات في **Google AI Studio**، اختر **Push to GitHub** أو قم بتصدير المشروع كملف ZIP ورفعه إلى مستودع GitHub الخاص بك.

2. **البناء التلقائي**:
   - بمجرد رفع الكود إلى الفرع `main` أو `master` (أو عند إنشاء Tag جديد مثل `v1.0.0`)، سيبدأ سير عمل GitHub Actions تلقائياً.
   - يمكنك متابعة تقدم البناء بالانتقال إلى تبويب **Actions** في مستودع GitHub.

3. **تحميل ملف APK المباشر**:
   - **الخيار الأول (من صفحة Releases - مستحسن)**:
     - انتقل إلى صفحة **Releases** في مستودعك على GitHub.
     - ستجد أحدث إصدار مع رابط مباشر لتحميل `AlThemat-debug.apk` مباشرة إلى هاتفك.
   - **الخيار الثاني (من تشغيل الـ Action)**:
     - ادخل إلى آخر تشغيل ناجح في تبويب **Actions**.
     - في أسفل الصفحة، اضغط على **AlThemat-Debug-APK** لتحميل الملف.

4. **التشغيل اليدوي (Workflow Dispatch)**:
   - يمكنك في أي وقت الذهاب إلى تبويب **Actions** > اختيار **Build & Release Android APK** > الضغط على **Run workflow** لبناء وتوليد APK جديد فوراً.

## 📲 كيفية تثبيت التطبيق على هاتفك

1. بعد تحميل ملف `AlThemat-debug.apk` على هاتفك، اضغط عليه لفتحه.
2. إذا طلب النظام الإذن، قم بتفعيل خيار **"السماح بتثبيت التطبيقات من هذا المصدر" (Install unknown apps)** لمتصفحك أو مدير الملفات.
3. اضغط على **تثبيت (Install)** ثم **فتح (Open)**.
4. استمتع بتجربة تطبيق الثيمات والويدجات المتقدمة!

## ⚠️ حل مشكلة "حدث خطأ أثناء تحليل الحزمة" (There was a problem parsing the package)

إذا ظهرت لك هذه الرسالة عند محاولة تثبيت التطبيق، فإليك الحلول المباشرة:
1. **التحميل من Releases مباشرة**: قم بتحميل ملف الـ `.apk` مباشرة من صفحة **Releases** بدلاً من تحميل الـ zip من Artifacts.
2. **فك الضغط إذا حملت من Artifacts**: يقوم GitHub بضغط ملفات الـ Artifacts في أرشيف `.zip`. إذا قمت بالتحميل من الـ Artifacts، يجب عليك فتح تطبيق "ملفاتي" أو "مدير الملفات" على الهاتف وفك الضغط أولاً قبل تثبيت ملف الـ APK.
3. **التأكد من اكتمال التنزيل**: تأكد من أن حجم الملف مطابق للحجم الموضح في صفحة الإصدار.
